# Changelog

## 1.0.0 - 2026-09-10

First public release of DeckBridge Input.

### Features

- Added 999 virtual Minecraft inputs: `D6_BUTTON_1` through `D6_BUTTON_999`.
- Added binding through the vanilla Minecraft Controls screen.
- Added persistent D6 bindings across game restarts.
- Added press and release handling for click and hold-style key mappings.
- Added a local-only HTTP bridge on `127.0.0.1:4567`.
- Added optional Controlling compatibility.
- Added optional Iron's Spells 'n Spellbooks compatibility for Spell Wheel, Cast Spell, Spell Bar Modifier and Quick Cast 1–15.
- Added support for the DeckBridge FIFINE D6 / StreamDock companion plugin.

### Release metadata

- Minecraft 1.19.2 only.
- Forge 43.x.
- Java 17.
- Client-side only.
